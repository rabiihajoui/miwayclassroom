Obtenir MI WAY Classroom

Gratuit, sans compte. Il vous faut un seul appareil : un ordinateur Windows ou un téléphone Android. Les élèves n'installent rien.

Le meilleur pour cet appareil 💻

Pour le professeur

Ordinateur Windows

Idéal avec un projecteur. Windows 10 et 11.

Très bientôt
  1. Téléchargez le fichier et ouvrez-le.
  2. Suivez les étapes d'installation. Cela prend 1 minute.
  3. Activez votre point d'accès ou le Wi-Fi et commencez la classe.
Windows peut afficher un avertissement bleu

More info1 Run anyway2
  1. Cliquez sur Informations complémentaires (More info).
  2. Cliquez sur Exécuter quand même (Run anyway).

C'est normal pour une nouvelle appli gratuite. MI WAY Classroom est sûre.

Le meilleur pour cet appareil 📱

Pour le professeur

Téléphone ou tablette Android

Votre téléphone gère la classe. Avec un projecteur ou une télé si vous en avez.

Disponible surGoogle Play
  1. Installez MI WAY Classroom depuis Google Play.
  2. Activez le point d'accès de votre téléphone.
  3. Les élèves scannent le QR code sur votre téléphone.

Vous enseignez avec un ordinateur ? MI WAY Remote est une application gratuite pour votre téléphone : dirigez la classe en marchant. Obtenez-la avec le QR code dans l'application de l'ordinateur.

🎓

Pour les élèves

Élèves

Rien à installer. Ils scannent le QR code en classe. Sur Android, ils peuvent aussi recevoir l'appli gratuite MI WAY Student depuis l'appli du professeur.

▶ Voir comment ça marche
  1. Rejoindre le point d'accès ou le Wi-Fi du professeur.
  2. Scanner le QR code au tableau.
  3. Toucher son nom et répondre.

Questions

Ça marche vraiment sans internet ?

Oui. Le point d'accès de votre téléphone ou votre ordinateur crée un petit réseau local. Les élèves s'y connectent. Aucune donnée mobile n'est utilisée.

C'est vraiment gratuit ?

Oui. Pas de pub, pas de version payante, pas de limite d'élèves. Une seule option, la création de quiz par IA, demande votre propre clé Claude payante.

De quoi les élèves ont-ils besoin ?

D'un téléphone avec un navigateur : Android ou iPhone. Ni appli ni compte.

Je n'utilise pas les manuels marocains. Puis-je l'utiliser ?

Oui. Vous pouvez taper vos propres leçons pour n'importe quel manuel et niveau.

Les données de mes élèves sont-elles protégées ?

Tout reste sur votre appareil. Rien n'est envoyé dans un cloud. Politique de confidentialité

Ça marche sur Mac ou iPhone pour le professeur ?

Pas encore. Le professeur a besoin d'un téléphone Android ou d'un ordinateur Windows. Les élèves peuvent utiliser n'importe quel téléphone.
